<h1>Sobre</h1>

<p>Projeto Interdisciplinar realizado no final do 1° período do Curso de Tecnologia em Sistemas para Internet no IFES Campus Santa Teresa. O objetivo foi produzir uma página web que gerencia produtos de um supermercado.</p>

<h2>Tecnologias Utilizadas:</h2>

- HTML 5;
- CSS 3;
- JavaScript.

<h2>Principais Funcionalidades:</h2>

- Criação da **Lista de Produtos** com descrição, categoria, marca, unidade de medida e preço;
- Botão para **adicionar produtos no carrinho**, atualizando o valor total da compra;
- Botão para **mostrar/esconder os produtos adicionados no carrinho**;
- **Filtros de busca** por descrição, categoria, marca e por preço mínimo e máximo;
- Relatório que mostra o **produto mais barato de uma categoria** determinada pelo usuário.

<h2>Como Executar</h2>

- Clone este repositório no seu pc;
- Abra o arquivo index.html no navegador;
- Explore as funcionalidades da página.
